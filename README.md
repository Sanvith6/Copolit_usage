# Copilot Usage

A Python project for demonstrating GitHub Copilot usage.

## Setup

### Prerequisites

- Python 3.9 or higher

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sanvith6/Coplolit_usage.git
   cd Coplolit_usage
   ```

2. Install the package in development mode:

   ```bash
   pip install -e ".[dev]"
   ```

## Usage

Run the main module:

```bash
python -m copilot_usage.main
```

## Running Tests

```bash
pytest
```
